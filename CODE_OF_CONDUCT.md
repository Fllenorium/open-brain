# Code of conduct

Open Brain follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short version: be kind, assume good faith, and criticise the work rather
than the person. Harassment, insults, and unwelcome personal attention aren't
tolerated in issues, pull requests, or anywhere else the project lives.

If someone's behaviour is a problem, contact the maintainer privately through
[@Fllenorium](https://github.com/Fllenorium) on GitHub. Reports are kept
confidential.
